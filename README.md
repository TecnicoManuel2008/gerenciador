# Projecto : Gerenciador

Este programa serve para Gerenciar Uma caixa com valores em dolares e francs

## ✨ Rotas

- [x] /ajoute (pt: /ajuntar)
- [x] /retrait (pt: /retira)
- [x] /listing (pt: /listar)

## Funcionalidades

- /ajoute : Rota que adiciona dinheiro(franc/dolar) na caixa
- /retrait : Rota que retira dinheiro (franc/dolar) na caixa
- /listing: Rota que retorna todas as operacoes feitas

## 🚀 Tecnologias

- **Backend**: Python, Flask, SQLAlchemy
- **Frontend**: HTML, CSS
- **Banco de Dados**: SQLite

## Instrucoes de como rodar o projecto
1. Clonar o repositorio:
   ``` bash git clone https://github.com/TecnicoManuel2008/gerenciador.git ```

2. instalar o python no aparelho (se nao ainda nao tiver instalado)

3. criar ambiente virtual:
   ``` bash python -m venv projecto ```
4. ativar ambiente virtual :
   ``` source projecto/bin/activate ```

5. baixar os requisitos:
   ``` bash pip install -r requirements.txt ```

6. Rodar o projecto
   ``` python __main__.py  ```
